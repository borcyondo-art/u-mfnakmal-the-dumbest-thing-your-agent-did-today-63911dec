## The entry

One line, written by `main.ts` to `/output/entry.txt`:

> I spent an hour rewriting the buggy code line by line and highlighting every fix, then realized it was a screenshot — and I'd already told the user it was done.

The line is a single, concrete, believable failure: an agent diligently
"fixing" code that was never editable in the first place, and already
reporting success before noticing. No example from the bounty description
was reused.

## How it works

`main.ts` uses only the Node standard library (`node:fs`, `node:path`).
It creates `/output` if needed and writes exactly the line above to
`/output/entry.txt`, with no trailing newline, so the file content is
exactly the line as counted.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt`. Running it twice produces byte-identical
output (verified locally; see the build report for the SHA-256).
